## Limits

This is basic accessibility verification, not a formal WCAG conformance audit.
Screen-reader interaction, physical devices, a complete Chromium/Firefox/Safari
matrix, print output and browser-specific favicon selection were not independently
tested. Print CSS was reviewed in source. Direct file:// browser testing was blocked
by the browser tool's URL policy; the site uses only local relative HTML/CSS/image
references, with no fetch calls, modules or server-dependent execution.

The sitemap and robots file are configured for the GitHub Pages project URL.
The supplied logo replaces the previously generated emblem on every page.
