What is The Open Computing Foundation?

OCF is an independent computing organisation founded by Colm Lenehan, with a contributor-led philosophy and an intended nonprofit operating model. Its work concerns computing independence, interoperability and access across platforms.

What is The Web Independence Initiative?

WII is OCF’s principal undertaking. It investigates how existing computing experiences could become accessible, compatible with, and wherever feasible native to the open web.

What is Ubiquity?

Ubiquity is the codename of WII’s central technical research and development project. The site describes its proposed scope and approaches; it does not announce a completed compatibility system.

Is Ubiquity a web browser?

No browser product is proposed here. The research concerns software execution and compatibility through standards-based browser technologies, using existing browsers where feasible.

Does Ubiquity aim to replace operating systems?

The objective is to reduce unnecessary dependence on particular operating systems for particular tasks. Browsers still rely on operating systems and hardware. Replacing all of their responsibilities is not the project’s stated scope.

Will every program become browser-compatible?

That cannot be promised. Hardware access, performance requirements, platform-specific services, anti-cheat systems, unavailable dependencies and licensing restrictions can make adaptation impractical or prevent it entirely. Compatibility must be evaluated per task and program.

What does web-native mean?

It describes software implemented around web execution and interaction models, rather than merely displaying a remote application’s interface. It can include local JavaScript or WebAssembly execution and browser-managed input, graphics and storage. It does not automatically mean offline, private or independent of servers.

How could existing games operate on the web?

Possible approaches include source-level ports, adapted engines, lawful emulation or web-specific reimplementations. Graphics, audio, controls, saved data and multiplayer services all need evaluation. A rendering demonstration does not establish complete game compatibility.

Is cloud streaming the same as web-native execution?

No. Streaming usually runs the application remotely and sends audiovisual output to the browser. It can provide access, but retains server and network dependencies. A web-native implementation runs through web execution capabilities, potentially with some network services.

Does Ubiquity require developers to release their source code?

No universal source-release requirement is proposed. Source access can make direct porting possible, but authors retain control under their licences. Other lawful approaches may sometimes be feasible. No approach removes the need for appropriate permission.

How will licensing and copyright be respected?

Each project would need to identify rights and obligations for code, binaries, libraries, firmware and assets. Adaptation and redistribution require the relevant permissions. Ubiquity is not intended to bypass licensing, digital rights management, security protections or ownership requirements.

Who leads OCF?

Colm Lenehan founded OCF. Its intended direction is contributor-led rather than founder-controlled. No established board, formal governance structure or current contributor body is asserted; those arrangements would need transparent development.

Is OCF a commercial company?

OCF is conceived as an independent organisation with a nonprofit operating model, not a commercial software company or subscription service. This does not claim legal registration, charitable status or tax exemption.

How can people contribute?

Possible future contributions include research, standards analysis, software porting, documentation, compatibility testing and accessibility review. No verified contribution channels have been supplied for publication. The contributing page explains potential areas without inventing a submission process.
